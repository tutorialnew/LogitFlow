# Глоссарий проекта

Термины закреплены заранее, чтобы код, тесты и интерфейс говорили на одном языке.

| Термин | Значение |
| --- | --- |
| **Заёмщик** (`BorrowerProfile`) | Малый бизнес, который хочет привлечь заёмные средства. Описан шестью признаками: выручка, возраст, долговая нагрузка, рентабельность, отрасль, обеспечение залогом. |
| **PD (Probability of Default)** | Вероятность дефолта заёмщика за горизонт 12 месяцев, `0…1`. Считается логистической регрессией. |
| **Логит** (`logit`) | Значение `Z = β₀ + Σ βᵢ·Xᵢ` до применения сигмоиды. Интерпретируется как «сырой» счёт риска. |
| **Коэффициент `βᵢ`** | Калибровочный вес признака в модели. Знак задаёт направление: `β > 0` — фактор повышает риск, `β < 0` — снижает. |
| **Центр признака** (`center`) | Опорное («безопасное») значение признака, относительно которого измеряется вклад. Задано в `MODEL_CALIBRATION`. |
| **Вклад фактора** (`contribution`) | `βᵢ · (Xᵢ − centerᵢ)`. Показывает, на сколько пунктов логита фактор сдвинул риск вверх или вниз. |
| **Грейд** (`grade`) | Буквенный рейтинг надёжности от `AAA` до `D`, присваивается по порогам PD. |
| **Ставка `r`** | Номинальная годовая ставка по займу, предлагаемая платформой. |
| **LGD (Loss Given Default)** | Доля потери при дефолте, `0…1`. По умолчанию 0.8: при дефолте инвестор теряет 80% вложенного. |
| **Безрисковая ставка** (`riskFreeRate`) | Доходность, которую инвестор получает без риска (депозит/ОФЗ). По умолчанию 18% — доходность ПДС на 2025 г. |
| **E(R)** | Ожидаемая доходность с учётом риска: `r·(1 − PD) − PD·LGD`. |
| **Премия за риск** | `E(R) − riskFreeRate`. Положительная — ставка перекрывает безрисковую. |
| **Ставка безубыточности** | Минимальная ставка `PD·LGD / (1 − PD)`, при которой `E(R) = 0`. |
| **Портфель** | Набор из `N` займов с равными или заданными долями. |
| **Пуассон-биномиальное распределение** | Распределение числа дефолтов в портфеле, когда вероятности дефолта займов различаются. Считается точным динамическим программированием. |
| **VaR 95%** | Доходность портфеля, которую инвестор не превысит с вероятностью 95%. |
| **CVaR 95%** | Средняя доходность в худших 5% сценариев — «глубина» хвостового риска. |
| **Эталон отрасли** (`benchmark`) | Средние безопасные значения для выбранной отрасли, с которыми сравнивается заёмщик. |
| **Seam (граница)** | Место, где модуль меняют снаружи. Согласованная граница проекта — один вход: `calculateAssessment(input) → Assessment`. |
