# LogitFlow — оценка инвестиционной привлекательности малого бизнеса

Одностраничное приложение для инвестора краудлендинга и краудинвестинга: даёт понять,
стоит ли вкладывать деньги в конкретный заём МСП и в какой портфель.

Всё считается в браузере. Бэкенда нет, расчёты реактивные, данные никуда не отправляются.

## Бренд

- **Название:** «LogitFlow» — отсылка к логистической регрессии, стоящей за моделью
- **Логотип:** тонкая сигмоида, вылетающая вверх латунной стрелкой, — сама S-кривая
  вероятности дефолта; инлайн-SVG в `src/ui/Logo.tsx`, никаких растровых ассетов.
- **Почта обратной связи:** `hello@logitflow.ru`

Предложение по доменному имени (в интерфейсе не показывается, для документации проекта):

| Вариант | Логика |
|---------|--------|
| `logitflow.ru` | Основной кандидат: имя + российская зона, аудитория — российские платформы |
| `logitflow.app` | Технический вариант: PWA-владелец и https-only из коробки |
| `logitflow.io` | Международный вариант для англоязычного ресёрча модели |

## Монетизация

Три уровня доступа (политика в `src/ui/plans.ts`, отдельные тесты на границу
`planLimits(plan) → лимиты`):

| Тариф | Цена | Что открывает |
|-------|------|----------------|
| **Оценка** | 0 ₽ навсегда | PD, грейд, скоринг, портфель до 10 займов, справка |
| **Инвестор** | 299 ₽/мес | Портфель до 50 займов, VaR/CVaR, копирование отчёта, сравнение сценариев |
| **Платформа** | 900 ₽/мес | Всё из «Инвестора» + свои калибровки модели, вставка сравнения на сайт |

Принципы честности:

- расчёт по одному заёму и объяснимый скоринг остаются бесплатными и полными;
- активация подписки в демо-версии эмуляруется на клиенте и честно об этом говорит:
  настоящие платежи требуют бэкенда и платёжного провайдера;
- выбор тарифа хранится в версионированном ключе `logitflow.plan.v1` без аккаунта;
- обратная связь не принуждает к подписке: письмо автору (`mailto:`) бесплатно, а
  предложение тарифа подстраивается под то, о чём сам пользователь написал.

## Что внутри

1. **Шкала надёжности** — вероятность дефолта за 12 месяцев на логарифмической шкале
   с девятью порогами грейдов от `AAA` до `D`, положение заёмщика относительно среднего
   по отрасли.
2. **Объяснимый скоринг** — разложение логита на вклад каждого из шести факторов
   (выручка, возраст, долговая нагрузка, рентабельность, отрасль, залог) и сравнение
   со средними безопасными значениями по отрасли.
3. **Доходность с учётом риска** — радар-профиль и формула
   `E(R) = r·(1 − PD) − PD·LGD` с вердиктом против безрисковой ставки.
4. **Портфельный симулятор** — точное пуассон-биномиальное распределение числа дефолтов
   для 1…50 займов, VaR/CVaR и наглядное сравнение диверсификации.
5. **Подписка и обратная связь** — уровни доступа (см. «Монетизация») и сбор письма
   автору без бэкенда; карта разделов помогает ориентироваться в структуре.
6. **Математическая справка** — формулы, коэффициенты, шкала грейдов и границы
   применимости модели; открывается прямо в интерфейсе на защите.

Четыре готовых кейса («Пекарня у дома», «IT-стартап», «Логистическая компания»,
«Производственное предприятие») подобраны так, чтобы давать разные выводы.

## Архитектура

Математическое ядро отделено от интерфейса. Наружу торчит **одна** функция:

```ts
calculateAssessment(input: AssessmentInput): AssessmentResult
```

Ни графики, ни таблицы не пересчитывают модель сами. Решения о структуре —
в [docs/ADR-001-math-core-seam.md](docs/ADR-001-math-core-seam.md),
термины — в [docs/GLOSSARY.md](docs/GLOSSARY.md),
формулы и калибровка — в [docs/MATH-SPEC.md](docs/MATH-SPEC.md).

```
src/
  domain/          математическое ядро: чистые функции, ноль импортов из React
    calculateAssessment.ts   согласованная граница модуля
    model.ts                 калибровка β, эталоны отраслей, шкала грейдов
    factors.ts               логит и разложение по факторам
    expectedReturn.ts        E(R), премия, ставка безубыточности
    riskProfile.ts           оси радар-чарта и сравнение с отраслью
    portfolio.ts             пуассон-биномиальное распределение
    presets.ts               демонстрационные кейсы
    __tests__/               40 тестов на согласованной границе
  ui/              React-слой: компоненты, графики, примитивы
    plans.ts           политика доступа: planLimits(plan) → лимиты тарифа
    contentMap.ts      карта контента — единый источник навигации и индекса
    backgrounds.ts     SVG-фоны, сгенерированные в data URI без сети
    Button.tsx         единая кнопка интерфейса
    Logo.tsx           знак (сигмоида-стрелка), название и почта бренда
```

## Стек

- React 18 + TypeScript 5.7, Vite 6
- Tailwind CSS 4, Recharts, Lucide
- Vitest для математического ядра (40 тестов) и политики доступа (8 тестов)

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173/try/
npm run test       # 40 тестов математического ядра
npm run build      # типизация + продакшен-сборка в dist/
npm run preview    # предпросмотр собранного сайта
```

## Деплой

Пуш в `main` запускает [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml):
установка зависимостей → тесты → сборка → публикация в GitHub Pages.
Сайт будет доступен по адресу `https://tutorialnew.github.io/try/`.

В первый раз в репозитории нужно включить Pages: **Settings → Pages → Source: GitHub Actions**.

Если репозиторий переименуют, поправьте `BASE_PATH` в `vite.config.ts` — GitHub Pages
отдаёт проект по адресу `/<имя-репозитория>/`.

## Границы применимости

Коэффициенты модели заданы экономической калибровкой, а не обучением на исторической
выборке: открытых размеченных данных по дефолтам российских МСП нет. Инструмент пригоден
для сравнения сценариев между собой, но не для оценки абсолютного уровня дефолтов на рынке
и не является инвестиционной рекомендацией. Подробности — в разделе «Границы применимости
модели» в интерфейсе и в [docs/MATH-SPEC.md](docs/MATH-SPEC.md).
